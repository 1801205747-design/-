# -# PyBullet Franka Panda 机械臂抓取仿真
基于 PyBullet 物理引擎实现的 Franka Panda 机械臂自动抓取仿真，完整覆盖**物理环境、逆运动学求解、关节/夹爪控制、抓取放置全流程**，与仿真架构图完全对应，开箱即用。

## 项目特性
- ✅ 完整复刻仿真架构：物理引擎 + 重力碰撞 + IK 求解 + 关节/夹爪控制
- ✅ Franka Panda 机械臂官方 URDF 模型加载
- ✅ 逆运动学（IK）自动求解目标位姿
- ✅ 平滑关节位置控制 + 夹爪开合控制
- ✅ 方块抓取→提升→移动→放置全流程自动化
- ✅ 代码模块化，易修改、易扩展

## 环境依赖
### 安装命令
```bash
pip install pybullet numpy
```
- **pybullet**：物理仿真引擎，提供机械臂模型、碰撞检测、运动控制
- **numpy**：数值计算辅助

## 快速运行
1. 复制完整代码保存为 `panda_grasp.py`
2. 直接运行脚本：
```bash
python panda_grasp.py
```
3. 自动弹出 3D 仿真窗口，机械臂自动执行抓取任务

## 代码架构（与架构图一一对应）
| 架构模块 | 代码实现 | 功能说明 |
|---------|----------|----------|
| 物理引擎 | `p.connect()` / `p.setGravity()` | 初始化仿真环境，设置重力 |
| 重力/碰撞检测 | PyBullet 内置 | 自动处理物体碰撞、重力物理效果 |
| 机械臂模型 | `franka_panda/panda.urdf` | 加载 Franka Panda 机械臂 |
| 逆运动学求解器 | `calculate_ik()` | 输入目标坐标 → 输出关节角度 |
| 关节控制器 | `move_arm()` | 机械臂平滑位置控制 |
| 夹爪控制器 | `control_gripper()` | 夹爪开合抓取/释放控制 |
| 目标坐标 | 自定义 3D 位置 | 抓取点、放置点、安全高度 |

## 执行流程
1. **初始化**：打开夹爪
2. **移动至物体上方**：到达安全位置
3. **下降抓取**：移动到物体位置
4. **闭合夹爪**：抓取方块
5. **提升物体**：回到安全高度
6. **移动放置点**：到达目标位置
7. **打开夹爪**：释放物体，任务完成

## 自定义修改
### 1. 修改抓取物体位置
```python
# 目标方块初始位置
boxStartPos = [0.5, 0, 0.1]
```
### 2. 修改放置目标位置
```python
# 放置目标坐标
target_pos = [0.2, 0.3, 0.3]
```
### 3. 调整运动速度
修改 `move_arm()` 和 `control_gripper()` 中的 `step` 参数：
- 数值越大 → 运动越慢
- 数值越小 → 运动越快

## 常见问题
1. **仿真窗口闪退**
   - 检查依赖是否安装完整
   - 使用 Python 3.7~3.11 版本运行
2. **机械臂抖动**
   - 增大 `step` 步数
   - 调整关节控制力参数
3. **抓取失败**
   - 微调抓取坐标 `grasp_pos`
   - 调整夹爪闭合位置
